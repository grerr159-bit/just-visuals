# 🔧 Инструкция по исправлению кодировки

## 📋 Проблема
В некоторых Java файлах могут появляться кракозябры вместо русского текста из-за неправильной кодировки.

**Примеры проблем:**
- `? ? ?'? ? ???????` вместо нормального текста
- `???` вместо русских букв
- Нечитаемые описания модулей

## ✅ Решение

### 🚀 Вариант 1: Автоматическое исправление (РЕКОМЕНДУЕТСЯ)

**Самый простой способ:**
1. Дважды кликните на файл `RUN_FIX.bat`
2. Дождитесь завершения
3. Готово!

### 🔧 Вариант 2: PowerShell скрипты

**Финальный скрипт (самый мощный):**
```powershell
powershell.exe -ExecutionPolicy Bypass -File final_fix.ps1
```

**Быстрый скрипт:**
```powershell
powershell.exe -ExecutionPolicy Bypass -File fix_all_encoding.ps1
```

**Простой скрипт:**
```powershell
powershell.exe -ExecutionPolicy Bypass -File fix_encoding.ps1
```

### 🐍 Вариант 3: Python скрипт (Кроссплатформенный)

1. Убедитесь, что установлен Python 3
2. Запустите скрипт:
   ```bash
   python fix_encoding.py
   ```

## 📊 Что делают скрипты?

1. ✅ Сканируют все `.java` файлы в проекте
2. 🔍 Определяют файлы с проблемами кодировки
3. 🔄 Пробуют различные кодировки (Windows-1251, CP866, ISO-8859-5, KOI8-R)
4. 💾 Конвертируют файлы в UTF-8 без BOM
5. 📈 Выводят подробный отчет о проделанной работе

## 🎯 После исправления

Рекомендуется пересобрать проект:

**Linux/Mac:**
```bash
./gradlew clean build
```

**Windows:**
```cmd
gradlew.bat clean build
```

## ✅ Исправленные файлы

- ✅ `SRPSpoof.java` - описание модуля теперь читается корректно
- ✅ `CustomWorld.java` - все настройки времени и тумана исправлены

## 🔧 Технические детали

### Поддерживаемые кодировки:
- **Windows-1251** (Кириллица Windows)
- **CP866** (DOS Кириллица)
- **ISO-8859-5** (ISO Кириллица)
- **KOI8-R** (Unix Кириллица)

### Целевая кодировка:
- **UTF-8 без BOM** (стандарт для Java проектов)

## 🛠 Устранение проблем

### Если скрипт не запускается:

**PowerShell (ошибка ExecutionPolicy):**
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Bypass
```

**Python (если не установлен):**
- Windows: Скачайте с [python.org](https://www.python.org/downloads/)
- Linux: `sudo apt install python3`
- Mac: `brew install python3`

### Если проблемы остались:

1. ✅ Проверьте, что файлы не открыты в редакторе
2. ✅ Убедитесь, что у вас есть права на запись
3. ✅ Попробуйте запустить от имени администратора
4. ✅ Проверьте, что файлы не защищены от записи

АЛЬТЕРНАТИВНЫЕ СПОСОБЫ:
-----------------------

Способ 1: Через PowerShell
   Откройте PowerShell в папке проекта и выполните:
   
   powershell.exe -ExecutionPolicy Bypass -File final_fix.ps1


Способ 2: Через Python (если установлен)
   
   python fix_encoding.py


ПОСЛЕ ИСПРАВЛЕНИЯ:
------------------

1. Пересоберите проект:
   
   gradlew.bat clean build

2. Проверьте исправленные файлы в вашей IDE

3. Закоммитьте изменения в Git (если используете)


ЧТО БЫЛО ИСПРАВЛЕНО:
--------------------

✅ SRPSpoof.java - описание модуля
✅ CustomWorld.java - настройки времени и тумана
✅ Все остальные файлы с проблемами кодировки


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК:
-------------------------

1. Запустите скрипт от имени администратора
   (Правый клик → Запуск от имени администратора)

2. Убедитесь, что файлы не открыты в редакторе

3. Проверьте права доступа к файлам

4. Если используете Git, сделайте откат:
   git checkout .


ТЕХНИЧЕСКИЕ ДЕТАЛИ:
-------------------

Скрипты автоматически:
• Находят все Java файлы с проблемами
• Определяют правильную кодировку
• Конвертируют в UTF-8 без BOM
• Создают отчет о проделанной работе


ДОСТУПНЫЕ СКРИПТЫ:
------------------

RUN_FIX.bat           - Автоматический запуск (ЛУЧШИЙ ВЫБОР)
final_fix.ps1         - Самый мощный PowerShell скрипт

fix_encoding.ps1      - Базовое исправление
fix_encoding.py       - Python версия
quick_fix.bat         - Быстрый запуск


ПОДДЕРЖКА:
----------

Если возникли проблемы:
1. Проверьте версию PowerShell (должна быть 5.0+)
2. Попробуйте запустить от администратора
3. Убедитесь, что антивирус не блокирует скрипты
